## Organizzazione del codice

Il progetto Angular si trova nella cartella `portfolio-angular`.

- `core`: configurazione e routing;
- `data`: dati tipizzati e riutilizzabili;
- `features`: pagine e funzionalità del portfolio;
- `layout`: elementi condivisi dell'interfaccia.

## Avvio in locale

### Requisiti

- Node.js in versione LTS
- npm

```bash
git clone https://github.com/fabiozagaria/fabio-zagaria-portfolio.git
cd fabio-zagaria-portfolio/portfolio-angular
npm install
npm start
```

L'applicazione sarà disponibile su `http://localhost:4200`.

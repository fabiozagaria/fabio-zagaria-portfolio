# Fonti dei loghi e delle bandiere

I percorsi sono relativi a `portfolio-angular/src/assets`. I marchi identificano le tecnologie citate nel profilo. Le immagini provengono dai siti e repository dei progetti o dai cataloghi Devicon, Simple Icons e Lobe Icons. Il logo Spring Data accompagna la voce Spring Data JPA. JavaScript usa il marchio della comunità e REST API è rappresentato con il suo nome.

La stella della pagina `/gioco` è disegnata dal codice (`features/gioco/pixel-art.ts`).

Lo sfondo `img/gioco-sfondo.webp` (tessera 320×640 senza cuciture, sfondo trasparente) è generato dallo script `portfolio-angular/scripts/generate-gioco-background.py` (Pillow e NumPy, seed 2811): nebulose a retino, stelle e sei galassie in pixel art, tutto in toni scuri. Non usa immagini esterne.

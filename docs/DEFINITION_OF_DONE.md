# Definition of Done
- [ ] Inventario, stato Git, istruzioni e impatto verificati.
- [ ] Fonti pertinenti lette; conflitti e blocchi dichiarati.
- [ ] Documenti impattati aggiornati, invariati motivati secondo AGENTS.
- [ ] Diff, link, test e build pertinenti verificati; limiti espliciti.
- [ ] Handoff aggiornato; decisioni e mappa allineate.
- [ ] Per cambi importanti applicare regola CV in AGENTS.
- [ ] Push e pubblicazione solo se autorizzati.

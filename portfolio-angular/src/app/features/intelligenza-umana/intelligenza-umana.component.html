Intelligenza Umana

Foundation pubblica · organizzazione GitHub attiva

Che cos’è

Intelligenza Umana è un laboratorio tecnologico indipendente che unisce ingegneria del software, ricerca applicata e collaborazione. L'iniziativa è orientata all'open source ed è attualmente gestita da me.

A cosa serve

A risolvere problemi concreti con software utile, sicuro, affidabile, comprensibile e verificabile: librerie, strumenti per sviluppatori, plugin e altri progetti indipendenti.

Perché esiste

Credo che l'intelligenza artificiale possa amplificare le capacità umane. Comprensione, ragionamento e responsabilità restano alle persone che progettano e verificano il software.

Come funziona

Si parte da un problema reale, si studiano alternative e si motivano le scelte. Il codice, anche quando è assistito dall'IA, richiede comprensione e revisione umana; controlli riproducibili e trasparenza sui limiti affiancano il giudizio delle persone.

Gli ambiti prioritari comprendono backend, sicurezza, integrità dei dati, algoritmi, sistemi distribuiti e affidabilità dell'IA.

Repository e progetti

Il registro ufficiale associa all’iniziativa quattro strumenti. I nomi portano ai repository canonici, tutti pubblici e con licenza MIT:

  • Learning Ledger: registro locale delle evidenze per l’apprendimento assistito. I test Python sono automatizzati; installazione e compatibilità con Claude Code restano da verificare.
  • Spring Security Advisor: assistente per la revisione di sicurezza di applicazioni Spring Boot; il punteggio non è una certificazione di sicurezza. I test Python sono automatizzati; installazione e compatibilità con Claude Code restano da verificare.
  • Project Lifecycle Skill v0.3.0: guida a contesto e passaggi di consegne tra sessioni di lavoro. I flussi nativi dei vari assistenti non sono ancora verificati.
  • IU Model Router v0.1.0: skill iniziale per instradare le richieste degli agenti di codice in base al compito; il comportamento negli assistenti non è ancora verificato.

A che punto è

La foundation documentale e i quattro strumenti elencati sono pubblici nell’organizzazione GitHub Intelligenza Umana; le repository sono state trasferite dall’account personale il 26 novembre 2026. La foundation è distribuita con licenza MIT. L’organizzazione ha un profilo pubblico e modelli condivisi per issue e pull request. La foundation è mantenuta dal fondatore e accoglie contributi; la scelta del progetto principale è ancora aperta.
